## Quick start

You can start a fresh new project with:

```bash [Terminal]
npm create nuxt@latest -- -t ui/saas
```

Or create a new repository from GitHub:

1. Open [github.com/nuxt-ui-templates/saas](https://github.com/nuxt-ui-templates/saas)
2. Click the `Use this template` button
3. Enter a repository name and click `Create repository from template`
4. Clone your new repository
5. Install dependencies with your favorite package manager
6. Start the development server

::callout{icon="i-lucide-circle-check" color="neutral"}
That's it. You can now start writing your documentation in the [`content/`](https://content.nuxt.com/usage/content-directory) directory.
::
